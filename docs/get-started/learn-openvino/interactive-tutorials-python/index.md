# Interactive Tutorials (Python)

> toolkit for optimized deep learning inference.

The tutorials show how to use various OpenVINO Python API features to run
optimized deep learning inference. They are not maintained on this website,
however, you can use the selector below to reach Jupyter notebooks from the
[openvino\_notebooks](https://github.com/openvinotoolkit/openvino_notebooks) repository.

Notebooks with ![Binder button](img/launch_in_binder.svg) and ![Google Colab button](img/open_in_colab.svg) buttons can be run in the
browser, no installation required. Just choose a tutorial and click the button.

[Binder](https://mybinder.org/) and [Google Colab](https://colab.research.google.com/)
are free online services with limited resources. For the best performance
and more control, you should run the notebooks locally. Follow the
\[Installation Guide\](interactive-tutorials-python/notebooks-installation.md) in order
to get information on how to run and manage the notebooks on your system.

If you have any issues with the notebooks, refer to the
[Troubleshooting](https://github.com/openvinotoolkit/openvino_notebooks/blob/latest/README.md#%EF%B8%8F-troubleshooting)
and
[FAQ](https://github.com/openvinotoolkit/openvino_notebooks/blob/latest/README.md#-faq)
sections in the
[Installation Guide](https://github.com/openvinotoolkit/openvino_notebooks/blob/latest/README.md#-installation-guide)
or start a GitHub
[discussion](https://github.com/openvinotoolkit/openvino_notebooks/discussions).
