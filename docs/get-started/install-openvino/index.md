# Install OpenVINO™ 2026.0

> of your choice.

OpenVINO 2026.0, described here, is not a Long-Term-Support version\!
All currently supported versions are:

  - 2026.0 (development)
  - 2024.6 (maintenance)

Effortless GenAI integration with OpenVINO GenAI

OpenVINO GenAI streamlines application development by providing LLM-specific interfaces for
easy integration of language models, handling tokenization and text generation.
For installation and usage instructions, check
\[OpenVINO GenAI installation\](../openvino-workflow-generative.md) and
\[inference with OpenVINO GenAI\](../openvino-workflow-generative/inference-with-genai.md).

Building OpenVINO from Source

OpenVINO Toolkit source files are available on GitHub as open source. If you want to build your own version of OpenVINO for your platform,
follow the [OpenVINO Build Instructions](https://github.com/openvinotoolkit/openvino/blob/master/docs/dev/build.md).
