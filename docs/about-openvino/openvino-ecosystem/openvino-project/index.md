# OpenVINO™ Tools Overview

This page provides an overview of the most noteworthy tools and components for AI developers,
hosted in repositories under the OpenVINO project:

**GenAI**  
`GitHub [https://github.com/openvinotoolkit/openvino.genai](https://github.com/openvinotoolkit/openvino.genai)` `User Guide [https://docs.openvino.ai/2026/openvino-workflow-generative/inference-with-genai.html](https://docs.openvino.ai/2026/openvino-workflow-generative/inference-with-genai.html)`

OpenVINO™ GenAI Library simplifies running inference of generative AI
models. Check the LLM-powered Chatbot Jupyter notebook to see how GenAI works.

**Neural Network Compression Framework**  
`GitHub [https://github.com/openvinotoolkit/nncf](https://github.com/openvinotoolkit/nncf)` `User Guide [https://docs.openvino.ai/2026/openvino-workflow/model-optimization.html](https://docs.openvino.ai/2026/openvino-workflow/model-optimization.html)`

A suite of advanced algorithms for Neural Network inference optimization with minimal accuracy
drop. NNCF applies quantization and sparsity algorithms to PyTorch models during training.

**OpenVINO Model Server**  
`GitHub [https://github.com/openvinotoolkit/model_server](https://github.com/openvinotoolkit/model_server)` `User Guide [https://docs.openvino.ai/2026/model-server/ovms_what_is_openvino_model_server.html](https://docs.openvino.ai/2026/model-server/ovms_what_is_openvino_model_server.html)`

A high-performance system that can be used to access the host models via request to the model
server.

**OpenVINO Notebooks**  
`GitHub [https://github.com/openvinotoolkit/openvino_notebooks](https://github.com/openvinotoolkit/openvino_notebooks)` `Jupyter Notebook Collection [https://docs.openvino.ai/2026/get-started/learn-openvino/interactive-tutorials-python.html](https://docs.openvino.ai/2026/get-started/learn-openvino/interactive-tutorials-python.html)`

A collection of Jupyter notebooks for learning and experimenting with the OpenVINO™ Toolkit.

**OpenVINO Test Drive**  
`GitHub [https://github.com/openvinotoolkit/openvino_testdrive](https://github.com/openvinotoolkit/openvino_testdrive)` `Overview Page [https://docs.openvino.ai/2026/documentation/openvino-ecosystem/openvino-project/openvino-test-drive.html](https://docs.openvino.ai/2026/documentation/openvino-ecosystem/openvino-project/openvino-test-drive.html)`

A cross-platform graphic user interface application for running and testing generative and
vision AI models on computers or edge devices.

**Tokenizers**  
`GitHub [https://github.com/openvinotoolkit/openvino_tokenizers](https://github.com/openvinotoolkit/openvino_tokenizers)` `User Guide [https://docs.openvino.ai/2026/openvino-workflow-generative/ov-tokenizers.html](https://docs.openvino.ai/2026/openvino-workflow-generative/ov-tokenizers.html)`

OpenVINO Tokenizers add text processing operations to OpenVINO.
